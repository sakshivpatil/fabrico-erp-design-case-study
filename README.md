# Fabrico Industries ERP — UI/UX Case Study

A UI/UX design case study for an internal ERP system designed for a textile manufacturing organization.

## 🔗 Live Demo

https://fabrico-industries.netlify.app/

## 📌 Project Overview

Fabrico Industries ERP is a role-based enterprise management system designed to support day-to-day operations in a textile manufacturing environment.

The system provides different interfaces and access levels for:

- Super Admin
- Admin
- Employee

The project focuses on creating a clear, structured, and efficient experience for managing employees, attendance, sales, reports, and operational activities.

## 🎯 Project Goals

- Create a structured ERP experience for different user roles
- Simplify access to frequently used information
- Organize complex enterprise data clearly
- Provide role-specific dashboards
- Improve usability and navigation
- Maintain a consistent visual design across the system

## 🖼️ Design Showcase

### Authentication
Role-based authentication interface for accessing the appropriate ERP panel.

### Employee Portal
Dashboard focused on employee-specific information such as attendance, workstation activities, and compensation.

### Admin Panel
Operations-focused interface for managing plant activities, attendance approvals, teams, dispatches, and reports.

### Super Admin Panel
Executive-level dashboard for managing employees, administrators, attendance, sales, reports, and system settings.
